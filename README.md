# LoreDev FakeServer

Eksperymentalny mod kliencki (Fabric, Minecraft 1.21.4): scoreboard, TAB, rangi, fake gracze, fake czat, rynek i komendy.

## Komendy moda
- `/fakeserver on | off | reload`
- `/fakeserver nick <nazwa>` - zmiana wyświetlanego nicku (`/fakeserver nick reset` - powrót do prawdziwego)
- `/fakeserver rank <nazwa>` - zmiana rangi (Tab podpowiada: VOID, DYNIA, BANAN, MEDIA, M+, H, H@)
- `/fakeserver money set <kwota> | add <kwota>`
- `/fakeserver shards <ilość>`
- `/fakeserver toggle <scoreboard|tab|chat|spam|joinleave|reply|komendy|give>`

Config: `.minecraft/config/loredev-fakeserver-v2.json`
